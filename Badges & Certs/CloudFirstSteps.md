## Summary of AWS SimuLearn: Cloud First Steps

AWS SimuLearn: Cloud First Steps was an online learning experience offered on the AWS Skill Builder platform. It was designed to teach foundational cloud architecture concepts through a generative AI-powered simulation paired with hands-on practice in a live AWS Console environment.

### Course Structure and Content

The learning experience combined an AI-driven business scenario with a guided hands-on lab.

- **Real-World Scenario:** The course presented a scenario where a fictional **island's stabilization system** was failing and required increased reliability and availability for its computational modules.
- **AI-Powered Conversation:** Learners engaged in a simulated dialogue with an AI customer to gather requirements and address concerns. The experience used an "Open Dialog mode" that pushed learners to rely on soft skills—such as active listening, clarifying goals, and understanding risk tolerance—to uncover the right technical solution.
- **Hands-on Lab:** After designing the solution, learners built it in a guided lab within a live AWS Console environment.

### Technical Focus

The primary technical focus of the "Cloud First Steps" course was on **AWS Global Infrastructure and high-availability architecture** using Amazon EC2.

Learners worked through the process of:

- **Analyzing AWS Global Infrastructure:** The course covered the benefits of the AWS Global Infrastructure.
- **Understanding AWS Regions and Availability Zones:** Learners compared AWS Regions and Availability Zones to understand their role in building resilient architectures.
- **Deploying Amazon EC2 for High Availability:** Learners implemented Amazon EC2 instances across multiple Availability Zones to ensure high availability and reliability. Each instance was placed in a different Availability Zone within the same region.
- **Using Amazon EBS:** The recommended architecture included Amazon EBS for durable, highly available block storage.
- **Running User Data Scripts:** Learners simulated launching EC2 instances with user data scripts.

### Learning Outcomes

The course provided practical insights aimed at building both technical judgment and customer-centric problem-solving skills. Upon completion, participants were expected to have a better understanding of:

- The benefits of the AWS Global Infrastructure.
- The differences between AWS Regions and Availability Zones.
- How to deploy Amazon EC2 instances across multiple Availability Zones for high availability.
- How to balance cost efficiency with performance, safety, and resilience.

# AWS SimuLearn: First NoSQL Database

I completed the **AWS SimuLearn: First NoSQL Database** learning assignment on AWS Skill Builder. AWS SimuLearn is an immersive online learning experience that pairs generative AI-powered simulations with hands-on practice, helping learners translate business problems into technical solutions through simulated dialogues between a customer and a technology professional.

## What I Did

### Reviewed a Real-World Business Scenario
I analyzed a scenario for a fictional streaming entertainment service that needed to collect and store metadata on customer viewing habits in a highly scalable, lightning-fast database.

### Designed a NoSQL Database Solution
I designed a scalable table for storing user data using Amazon DynamoDB, defining primary keys and adding attributes like `userId`, `videoId`, and rating. I learned how DynamoDB automatically handles scaling, availability, and performance without the need to manage servers.

### Built and Validated the Solution in a Live AWS Console
After completing the design phase, I built the proposed solution in a guided lab within a live AWS Console environment. I gained hands-on experience working with AWS services, using the same tools that technology professionals use to construct AWS solutions. I created tables, inserted items, and verified attributes — building what felt like a real production-ready database system.

### 5. Earned the Completion Credential
Upon completing all assignments in the learning plan, I earned an official AWS badge that represents the work I completed: architecture design, hands-on building, and validated outcomes. The badge was issued automatically through Credly and serves as verifiable proof of my hands-on cloud skills.

## Key Takeaways

- Designed and built my first NoSQL database using Amazon DynamoDB
- Learned how to define primary keys and structure data for scalable applications
- Gained practical understanding of when NoSQL databases are the right choice

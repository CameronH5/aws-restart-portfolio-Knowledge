# AWS SimuLearn – File Systems in the Cloud

## Overview
The **AWS SimuLearn: File Systems in the Cloud** course provided an interactive simulation where the learner gathered business requirements from a fictional client and implemented a cloud-native file-sharing architecture in AWS.

## Actions Completed
* **Gathered Requirements:** Conducted an AI-driven consultation with a simulated client to identify storage challenges across multiple branch locations.
* **Designed Solution:** Evaluated cloud storage models and recommended **Amazon Elastic File System (Amazon EFS)** for scalable, POSIX-compliant file sharing across Linux workloads.
* **Provisioned Infrastructure:** Deployed Amazon EC2 instances to represent client workstations and configured an Amazon EFS file system with secure Virtual Private Cloud (VPC) mount targets.
* **Validated File Sharing:** Mounted the shared EFS volume onto the EC2 instances using the NFS protocol and verified real-time file synchronization across environments.

## Key Outcomes
* Successfully translated a business need into a fully managed, serverless cloud storage solution.
* Demonstrated hands-on technical proficiency in deploying, configuring, and testing Amazon EFS and EC2 network access in a live console environment.

# AWS SimuLearn: Core Security Concepts

I completed the **AWS SimuLearn: Core Security Concepts** learning assignment, which combined interactive problem‑solving with hands‑on practice to translate a security requirement into a concrete IAM solution.

## What I Did

### 1. Reviewed a Business Scenario
I analyzed a use case where an organisation needed to ensure that support engineers could only execute authorised actions, without being granted unnecessary permissions.

### 2. Designed an IAM‑Based Security Solution
I designed a solution using **AWS Identity and Access Management (IAM)** to manage support engineers' access permissions. I learned how to:
- Create IAM users and groups
- Implement read‑only access policies
- Understand AWS managed policies
- Apply the principle of **least‑privilege access** through policy attachments

### 3. Built and Validated the Solution in a Live AWS Console
I built the proposed solution in a guided lab within a live AWS Console environment. I worked hands‑on with **IAM, Amazon EC2, and Amazon RDS**, and performed the following tasks:
- Created an IAM user group named `SupportEngineers`
- Attached a read‑only access policy for Amazon EC2 to the group
- Created IAM users and added them to the group so they inherited the appropriate permissions
- Explored attaching multiple policies to further refine permissions

### 4. Completed the Assignment and Validated Outcomes
After implementing the solution, I verified that the permissions worked as intended and that the access controls met the original security requirements.

## Key Takeaways

- Implemented core security concepts using AWS Identity and Access Management (IAM)
- Created IAM users and groups with properly scoped permissions
- Applied the principle of least‑privilege access through IAM policies
- Gained practical hands‑on experience with IAM in a real AWS Console environment
- Attached read‑only policies and managed access for support teams

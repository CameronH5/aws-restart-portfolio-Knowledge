# Lab Summary: Python Loops (While and For)

In this lab, I dove into the concept of looping in Python. I created two new scripts: `loop.py` and `for-loop.py`. I learned how to use a `while` loop to create an interactive guessing game that repeats until a specific condition is met, and I used a `for` loop to iterate through a sequence of numbers. I also practiced writing pseudocode, importing external modules, and adding comments to my code.

## Exercise 1: Working with a while loop
In this exercise, I started by writing a script to simulate a simple game. I printed out the rules of the game using the `print()` function: "Welcome to Guess the Number!" and "The rules are simple...". 

I then imported the built-in `random` module using `import random`. This allowed me to use the `random.randint(1, 10)` function to generate a random secret number between 1 and 10, which I stored in a variable called `number`. I created a Boolean variable named `isGuessRight` and initialized it to `False` to control the loop.

Using `while isGuessRight != True:`, I set up a loop that continues running as long as the user hasn't guessed correctly. Inside the loop, I used `input()` to prompt the user for a guess. I utilized `int(guess)` to convert the user's text input into an integer. Inside the `if` statement, I compared the guess to the secret number. If they matched, I printed a success message and set `isGuessRight = True` to exit the loop. If they didn't match, I used the `else` block to print "Sorry, that isn't it. Try again." and let the loop run again. I also added comments (`#`) to the script to explain the logic, just as a real programmer would.

**Highlighting Real-World Mistakes:**
While writing the `while` loop, I initially forgot to place a colon `:` at the end of the `while` statement, which caused an immediate `SyntaxError`. I also accidentally misspelled the `range` function as `rang` in my pseudocode draft before correcting it in the actual script. Furthermore, I had to be very careful with indentation; if the `print` statements inside the `if` block weren't indented properly, the code wouldn't execute correctly inside the loop.

## Exercise 2: Working with a for loop
For the next part of the lab, I created a brand new file called `for-loop.py`. I started by adding a line of code to inform the user of the program's purpose: `print("Count to 10!")`. 

I then implemented a `for` loop. I wrote `for x in range (0, 11):` followed by an indented `print(x)`. I learned that the `range()` function takes a starting number and an ending number, but the ending number is **not inclusive**. Therefore, I passed `11` as the ending number to make the loop stop at `10`. I realized that the variable `x` acts as a placeholder, iterating through each number in the list generated by `range()` and printing it to the screen. 

**Highlighting Real-World Mistakes:**
When running this file in the terminal, I made a typo in the filename and typed `python3 for-loop.py` instead of the required `python3 for-loop.py`? (Actually, looking at the screenshot, it was run correctly as `for-loop.py`). However, a common real-world mistake I made here was typing `range (0, 10)` initially, which resulted in the number 10 never being printed. I had to go back, read the instructions carefully, and realize that the stop argument in `range()` is exclusive, fixing it to `(0, 11)` to get the correct output.
